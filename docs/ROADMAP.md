## 高优先级未决事项

1. 请求官方提供2022—2025年区表归集与年报缴存的逐项调节；四年差额均与缴存人利息支出接近，但有约6—7亿元残差。
2. 记录2024、2025年人群分类变更及可能存在的统计口径断点。
3. 向主管部门申请**不识别个人的汇总交叉表**（申请草案见 reports/information_requests.md）。
4. 2025年单位决算已取得；继续申请管理费用“增值收益上缴财政→机构财政拨付”的现存账务调节说明。
5. 对存款期限、资金成本和受托贷款收益进行加权、动态、可比核算，不宣称定期存款闲置。
6. 仅在有足够对照数据时研究政策因果效应。

研究成果允许与预设假说不一致；任何结论若缺少证据应降级或撤回。

## 新的独立研究线索（第二轮）

1. **财政账桥接**：核对管理中心2025单位财政预算、决算与公积金年度管理费用的款项归属，不重复计算。
2. **交易市场交叉验证**：用上海统计局房地产统计对照新房/二手房公积金贷款，建立同口径交易笔数与申请人数分母。
3. **资格漏斗与人群福利**：利用2023年贷款管理办法构建资格、申请、批准与放款各层次分组指标。
4. **执法统计分母**：核实年报4441件、2413件及55.86%之间的统计对象和案件范围。
5. **反向文献证据**：独立审核CHFS、CHIP和城市面板上互相不一致的公积金不平等研究结论，详见 [LITERATURE_AND_IDENTIFICATION.md](LITERATURE_AND_IDENTIFICATION.md)。
6. **开放数据新路径**：若公共数据开放平台提供机器可读数据，用它复核已经取得的768条官方网页数据；需核查实际接口和可下载权限。
