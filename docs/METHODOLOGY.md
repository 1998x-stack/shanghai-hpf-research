# 研究方法与统计口径

## 数据处理原则
- **证据层级**：官方原始页面/文档 → 原始转录表 → 机器计算结果 → 研究解释与竞争性假说。
- **单位约定**：金额亿元（100m CNY）、人数万人（10k persons），区级原表金额万元换算为亿元须除以10,000。
- **覆盖率**：2022—2025年每年16个行政区 × 12个月 = 192地区-月份记录，四年共768条，已从48份官方HTML核验。
- **时间**：年度缴存和提取为全年流量；贷款和缴存余额为期末存量；月度分区金额为年初至当月累计。
- **地区**：行政区按缴存单位归属统计，不能直接对应居住地、房价或居民平均工资。
- **群体**：2024细分单位性质；2025分类为企业/非企业/灵活就业，不作未经证实的直接映射。

## 可验证的财务恒等式
\`\`\`
年末缴存余额 = 上年末缴存余额 + 当年缴存 - 当年提取 + 披露的其他调整
年末住房贷款余额 = 上年末住房贷款余额 + 发放 - 回收 - 资产证券化转出 + 其他调整
增值收益 = 业务收入 - 业务支出
\`\`\`

2016年资产证券化转出312.02亿元必须显式调整，否则跨年贷款余额无法对账。其余年份如出现与已知公式不符的残差，先查财务和统计口径，不通过修改原始值强行平账。

计算验证容差为 ±0.021亿元，只针对公开报表两位小数舍入误差；它**不是**经济重要性阈值。

## 统计和因果边界
不能从“某区累计提取占比较高”推出当地居民住房负担高，也不能从“存款规模上升”推出闲置。不能从“平均贷款额上升”推出贷款政策偏向高收入群体。

真正识别福利分配至少需要 **单位性质 × 缴存金额** 和 **收入/住房状况 × 贷款申请与审批** 的交叉数据。没有这些数据时提供假设区间，避免点估计冒充事实。政策因果评估需要可信对照组、事前趋势及安慰剂检验。

## 独立检查
执行 `python -m hpf_research.audit`，检查2016—2025逐年两套资金勾稽、2024/2025财务收支、2025年192条地区月度唯一性与累计值单调性；执行 `python -m pytest -q` 独立测试。`python -m hpf_research.collect_monthly --year 2022`（改为2023、2024、2025）可重新抓取对应12份HTML并计算SHA-256；重采前应保留旧版快照。`python analysis/scripts/build_outputs.py` 从版本化CSV生成派生表、公式型Excel、图和计算日志。

## 官方来源
[2015—2025官方年度报告目录](https://www.shzfgjj.cn/html/newxxgk/ndbg/index.html) · [月度业务数据目录](https://www.shzfgjj.cn/html/newxxgk/ywsjtj/index.html) · [2025年报告](https://www.shzfgjj.cn/html/newxxgk/ndbg/228312.html)。

48份月报、11份年报HTML及政策、财政预算、统计公报等来源已归档；逐份网址、发布机构、发布日期、期间、获取日期、版本说明、SHA-256见 [`manifest.csv`](../sources/manifest.csv)。并非所有可能存在的内部汇总表都已公开；缺失登记见 [`data_gaps.csv`](../data/processed/data_gaps.csv)。

**区表与年报不能无调节合并**：2025年12月区表归集总额2,532.044973亿元，年报“缴存额”2,663.65亿元，差额131.605027亿元；区表提取额与年报在舍入范围内一致。结转利息可能影响定义，但当前没有官方调节表，差额保留为待核实。月度增量只能由同区相邻累计额相减得到。详细计算见[月度面板报告](../reports/monthly_panel_2025.md)。

四年桥接发现，2022—2025归集差额分别为92.516798、105.549423、118.325788、131.605027亿元；对应缴存人利息支出为98.79、111.77、125.20、138.15亿元。差额减利息支出稳定在-6.22至-6.87亿元之间，说明利息是有力的**解释候选**，但不是已经确认的逐项调节。

## 第二轮跨来源统计约束

年度缴存额含汇缴、补缴及结转利息，不应直接当作纯工资缴存；年内实缴人数只要求至少1次汇缴或补缴，不是连续12个月活跃人数。房地产新建住宅销售面积、存量房买卖登记面积与公积金贷款笔数的分母不同，禁止直接相除求“公积金渗透率”。财政单位预算是计划数，公积金年报管理费用是执行数，必须建立口径桥接才允许比较。

见 [第二轮跨来源实证](SECOND_PASS_EVIDENCE_2026-10-27.md)。

## 新增：结息入账时点与费用确认时点

年报财务利息支出按日历年度列报，6月结息公告属于上一年7月至当年6月的实际入账。二者不能互换。2022—2025年年报缴存减区表归集额，与同年6月实际结息比，与利息费用比残差较小，但并不能构成正式会计调节。见 [结息桥接](../reports/interest_settlement_bridge_2022_2025.md)。结息账户数与年内实缴职工人数统计对象不同，不能推算封存人数。
