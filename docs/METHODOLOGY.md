# 研究方法与统计口径

## 数据处理原则
- **证据层级**：官方原始页面/文档 → 原始转录表 → 机器计算结果 → 研究解释与竞争性假说。
- **单位约定**：金额亿元（100m CNY）、人数万人（10k persons），区级8月原表金额万元换算为亿元须除以10,000。
- **覆盖率**：16个行政区 × 12个月 = 192地区-月份记录。只取得2025年8月16条，其余字段留空。
- **时间**：年度缴存和提取为全年流量；贷款和缴存余额为期末存量；月度分区金额为年初至当月累计。
- **地区**：行政区按缴存单位归属统计，不能直接对应居住地、房价或居民平均工资。
- **群体**：2024细分单位性质；2025分类为企业/非企业/灵活就业，不作未经证实的直接映射。

## 可验证的财务恒等式
\`\`\`
年末缴存余额 = 上年末缴存余额 + 当年缴存 - 当年提取 + 披露的其他调整
年末住房贷款余额 = 上年末住房贷款余额 + 发放 - 回收 - 资产证券化转出 + 其他调整
增值收益 = 业务收入 - 业务支出
\`\`\`

2016年资产证券化转出312.02亿元必须显式调整，否则跨年贷款余额无法对账。其余年份如出现与已知公式不符的残差，先查财务和统计口径，不通过修改原始值强行平账。

计算验证容差为 ±0.021亿元，只针对公开报表两位小数舍入误差；它**不是**经济重要性阈值。

## 统计和因果边界
不能从“某区累计提取占比较高”推出当地居民住房负担高，也不能从“存款规模上升”推出闲置。不能从“平均贷款额上升”推出贷款政策偏向高收入群体。

真正识别福利分配至少需要 **单位性质 × 缴存金额** 和 **收入/住房状况 × 贷款申请与审批** 的交叉数据。没有这些数据时提供假设区间，避免点估计冒充事实。政策因果评估需要可信对照组、事前趋势及安慰剂检验。

## 第二轮跨来源统计约束

年度缴存额含汇缴、补缴及结转利息，不应直接当作纯工资缴存；年内实缴人数只要求至少1次汇缴或补缴，不是连续12个月活跃人数。房地产新建住宅销售面积、存量房买卖登记面积与公积金贷款笔数的分母不同，禁止直接相除求“公积金渗透率”。财政单位预算是计划数，公积金年报管理费用是执行数，必须建立口径桥接才允许比较。
