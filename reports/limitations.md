# 当前研究局限与证据边界（2026-10-27）

本项目已归档[来源台账](../sources/manifest.csv)中的全部可取得原件，形成2022—2025年四年、16区、每年12月的**768条**区月记录，并完成2015—2025年度资金账勾稽。以下缺口仍改变可作出的结论；逐项记录见 [`data_gaps.csv`](../data/processed/data_gaps.csv)。

| 问题 | 已掌握的证据 | 不能得出的结论 |
|---|---|---|
| 群体单位缴存福利 | 2024/2025缴存人数结构、2025比例和基数规则 | 机关、国企、民企的人均单位缴存额或总额占比 |
| 贷款群体获益 | 2024收入组的缴存人和借款人构成、2025借款人年龄及房型 | 2025年收入组获贷概率、申请通过率及因果福利效应 |
| 区表归集与年报缴存 | 2022—2025四年的逐月区表、年报与利息支出 | 差额的官方逐项归属；不能称资金缺失 |
| 租房政策 | 2024年11月生效规则、年度租房提取金额、四年区级总提取 | 因为缺租房事项月度金额及有效对照，不能识别政策净效应 |
| 资产流动性与收益 | 期末存款分类、贷款余额、收入支出 | 1—90天可动用现金、真实加权资产收益、期限错配程度 |
| 风险准备金 | 年度计提、期末余额、国家通用规则 | 上海当年具体计提办法是否完全遵从、压力损失覆盖程度 |
| 管理费与财政资金 | 2024/2025机构决算、2025预算、公积金年报管理费；两年财政拨款与管理费上缴额在舍入范围内接近 | 仍缺上缴与拨付交易台账，不能确认全部拨款来源或判定重复补贴 |
| 住房金融市场 | 新房销售面积、存量房登记面积、贷款笔数 | 同口径公积金贷款渗透率或房型交易转换率 |

2022年特殊经济冲击会影响月度趋势解释；2023—2025年4月和9月提取高峰的重复出现支持季节性或操作批次等竞争性机制，但没有按事项分月数据，无法将其确定为具体原因。2024年按单位类型和收入组的较细披露在2025年消失，跨年拼接这些分类将造成虚假的分布变化。区级统计是管理归属，非居民居住区。

政策估值中的商业贷款利率、还款期限和提取冲击均为**假设情景**；Excel中的敏感性表不得解释为实际财政支出。所有尚未取得的交叉表只列入[信息公开申请草案](information_requests.md)，未经用户授权没有提交。

未开展北京、广州、深圳的排名式比较：当前上海研究的关键问题是区表与年报口径、群体申请分母及机构两账桥接；其他城市的分类和资产口径尚未逐项统一，直接横向比较会引入新的不可比性。
