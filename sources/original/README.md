# 官方及政府公开原件

本目录保存2026-10-27获取的2015—2025年11份上海住房公积金年报、2022—2025年48份16区月报及政策、机构预算决算、统计公报、国家法规等原件。全部79条[来源台账](../manifest.csv)记录发布机构、原网址、发布日期、数据期间、获取日期、文件路径、版本说明和SHA-256；四年月报各自另有 `monthly_YYYY/provenance.csv`。

月报可用 `python -m hpf_research.collect_monthly --year YYYY` 重采；2015—2025年报核心77项数字的相邻标签核对记录见 [`../../data/processed/annual_source_audit.csv`](../../data/processed/annual_source_audit.csv)。原件归其权利主体所有。官网后续若更正，应保留旧版并另存新快照，不静默覆盖既有证据。
